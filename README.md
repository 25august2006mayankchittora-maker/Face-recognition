# Face Recognition / Face Detection using OpenCV

## Description
This project detects human faces in images using OpenCV and Haar Cascade classifier.  
It takes an input image and draws a rectangle around detected faces.

This project is made to understand basic computer vision concepts using Python and OpenCV.

## Features
- Detects face from an image
- Draws bounding box around face
- Uses Haar Cascade classifier
- Easy to run

## Tech Stack
- Python  
- OpenCV

## How to Run
1. Clone the repository  
2. Install dependencies  
   `pip install -r requirements.txt`
3. Run the program  
   `python src/face_detect.py`

## Output
The program detects faces and displays a rectangle around them.
